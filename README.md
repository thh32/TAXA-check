# TAXA-check
TAXA-check: a browser extension for navigating changing prokaryotic nomenclature

TAXA-check highlights prokaryotic names in your web browser, providing information if a name has been reclassified or another name is recommended for medical use (present on the 'List of Recommended Names for bacteria of medical importance' (LoRN)).

## Understanding the different nomenclature codes
Currently there are two codes for naming (nomenclature) of prokaryotes;
- International code on the nomenclature of Prokaryotes (ICNP) is culture dependant (type material is a cultured isolate which is deposited in two culture collections)
- SeqCode which is culture independant (type material is a genome)

TAXA-check provides information for a name using both of these codes, letting you see if your taxon has a different name in each or is only valid in one and not the other.


## Installation guidance
1. Download the zip file here; [TAXA-check](https://github.com/thh32/TAXA-check/blob/main/TAXA-check-v1.zip)
2. Unzip the package
3. On Chrome, click on 'Manage Extensions'
4. Enable Developer mode
5. Select 'Load unpacked' and select the unzipped `TAXA-check` folder
